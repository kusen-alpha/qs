## 一、结论速览

1. **同花顺 App 内部的行情数据并不走 HTTP JSON 接口，而是走私有 TCP 二进制行情协议。** APK 中能找到行情服务器发现接口（端口 `9528`），但真正的报价、五档、逐笔数据由 native 行情 SDK 按私有协议收发，不能直接当普通 REST 接口使用。
2. **自选股“列表本身”在未登录时保存在本地（SQLite/SP）**；云端自选股同步接口（`ugc.10jqka.com.cn/optdata/selfstock/...`）必须登录，未登录实测返回 `401 auth failed`，不满足“免费、不需要登录”。
3. **真正无需登录、可直接调用的免费接口，主要是同花顺 Web/H5 同源的公开行情与资讯接口**，其中自选股场景最常用的是：

## 二、APK 分析过程与关键发现

### 2.1 文件结构

- `classes.dex` ~ `classes11.dex`：共 11 个 dex，约 90 MB。
- `lib/arm64-v8a/libapp.so`：Flutter 业务代码。
- `lib/arm64-v8a/libhx*.so`、`libhexin.so`、`libhxsecurity.so` 等：行情、安全、网络等 native SDK。
- `assets/RS/rs.rc` ~ `rs7.rc`：同花顺自有的字符串资源包，大量接口 URL、参数名、类名都保存在这里。

分析方法：

1. 解压 dex、Flutter 库、`assets/RS/*.rc`、`lib/arm64-v8a/*.so`；
2. 对 dex / so / 资源包做 ASCII 字符串与 URL 正则提取；
3. 对提取出的接口逐个发起真实请求，确认是否需要登录、返回结构；
4. 用交易所公开口径做交叉校准（仅用于人工核验，不作为数据源）。

### 2.2 自选股数据链路

```
自选股列表
├── 未登录：本地 SQLite / SharedPreferences（无 HTTP 接口）
└── 已登录：云端同步
    └── https://ugc.10jqka.com.cn/optdata/selfstock/open/api/...
        └── 未登录访问返回 401 auth failed

自选股行情
├── App 内：私有 TCP 二进制行情协议
│   ├── 服务器发现：eq.10jqka.com.cn/interface/common_data/sjzzdefaultstation.txt
│   └── 服务器：ip:9528（vip/移动/电信/联通多线路）
└── Web/H5 同源：d.10jqka.com.cn 的 realhead / time / line（本文件重点）
```

### 2.3 通用约定（接入必读）

#### 2.3.1 三种 JSONP 封装，不能混用

同一个域名下三种响应结构并存：

| 接口 | 顶层结构 | 取值方式 |
|---|---|---|
| realhead | `{"items": {...}}` | 行情字段与证券元信息**全部在 `items` 里** |
| time | `{"hs_600000": {...}}` | 顶层 key 就是 symbol |
| line | `{"num":..., "year":..., "data":"...", ...}` | 字段直接在顶层 |

> 2026-10-31 实测：realhead 的 `name/marketid/stockStatus/time/updateTime` 等元信息**也在 `items` 内**，不是在 `items` 外层（早期样本曾出现外层写法，务必兼容）。
>
> ```python
> it = d.get("items", d)
> name = it.get("name") or d.get("name")
> ```

通用解析函数（三种结构都适用）：

```python
import json
import re
import requests

H = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                  "(KHTML, like Gecko) Chrome/120 Safari/537.36",
    "Referer": "https://stockpage.10jqka.com.cn/",
}

def jsonp(url, timeout=15):
    r = requests.get(url, headers=H, timeout=timeout)
    m = re.search(r"\((.*)\)\s*;?\s*$", r.text, re.S)
    if not m:
        return None          # 空响应 / 错误页 / 非 JSONP
    return json.loads(m.group(1))
```

#### 2.3.3 请求头、HTTPS、编码、CORS

- **HTTP/HTTPS**：`http://` 与 `https://d.10jqka.com.cn` 均实测 200，生产请用 HTTPS。
- **压缩**：`d.10jqka.com.cn` 返回 `Content-Encoding: gzip`，`requests` 会自动解压。
- **User-Agent**：`news.10jqka.com.cn` 不带 UA 直接返回 **403 `Nginx forbidden`**；其他接口不带也能通，但建议统一带浏览器/手机 UA。
- **Referer**：建议 `https://stockpage.10jqka.com.cn/`；抓 `q.10jqka.com.cn` 时用 `https://q.10jqka.com.cn/`。
- **编码**：`d.10jqka` 的 JSONP 是纯 ASCII（中文为 `\uXXXX`，直接 `json.loads`）；`news`/`eq` 是 UTF-8 JSON；F10/板块 HTML 是 **GBK**，必须 `r.encoding = "gbk"`。
- **CORS**：`d.10jqka.com.cn` 与 `eq.10jqka.com.cn/open/api/*` 返回 `Access-Control-Allow-Origin: *`，浏览器可直连；**`news.10jqka.com.cn` 不返回 CORS 头**，前端直连会被浏览器拦截，必须服务端代理。
- **缓存头**：`d.10jqka`、`eq/open/api`、`q.10jqka` 均返回 `Cache-Control: max-age=60`。

#### 2.3.4 超时、并发、缓存、重试（建议值）

| 项 | 建议 |
|---|---|
| 超时 | JSON 接口 `(3, 10)` 秒；F10/板块 HTML `(5, 25)` 秒 |
| 并发 | 实时行情 ≤ 5；HTML 页面 ≤ 3（单页 50~200 KB） |
| 缓存 | realhead 3~10 s；分时 30~60 s；K 线收盘后缓存到次日；申万/板块成分股 7 天以上 |
| 重试 | 仅对超时/5xx 重试 1~2 次，指数退避（0.5 s / 1 s）；**404/401 不要重试** |
| 限频 | 未观测到 429；按上述并发与缓存执行，避免无缓存的全量轮询 |

#### 2.3.5 错误与“空数据”判定

| 现象 | 含义 | 处理 |
|---|---|---|
| HTTP 404 + 0 字节 + `application/javascript` | 代码/品种不支持（无效代码、港股、美股、可转债、深 B、退市股） | 视为“无此证券”，不重试 |
| HTTP 200 + 0 字节 | 北交所旧代码段（43x/83x/87x）等 | 视为“不支持”，降级或隐藏 |
| 200/401 + 非 JSONP（HTML/脚本） | 触发风控（如 `chameleon` 挑战页） | 降频、换会话；不要死循环重试 |
| JSONP 正常但 `data` 为空串 | 当日无数据（停牌、未开盘、非交易日） | 结合 `updateTime`/`stop` 判断 |
| `items["10"] == ""` 或 `0` | 无最新价 | 视为停牌/无行情 |
| `stockStatus` 为 `闭市` / `--` | 非交易状态（盘后、指数、板块） | 可正常展示，但不要当“交易中” |
| `37/38/39 = -1` | 个股/ETF 没有“成分股/涨跌家数”概念 | 正常，忽略 |
| 字段为 `""` 或 `-1` | 该品种无此口径 | 业务侧用 `None` 兜底 |
| `data` 记录字段数不足 | 停牌日/新股/异常记录 | 跳过该条，不要整文件失败 |

> `stop` 实测为数字 `0`（不是字符串），停牌时非 0（未逐一验证）。`items` 里的数值大多为字符串，但类型并不统一，**统一宽松解析**：`float(v) if v not in ("", None) else 0.0`。

#### 2.3.6 字段置信度分级

- **确认**：已与交易所/第三方行情交叉核对，可直接用于展示与计算。
- **推断**：由数值关系推得（如资金流四档），可用于展示，不要用于结算。
- **未确认**：口径不明（`49/74/75/527198` 等），**不要依赖**；业务必须使用时，请先用多日样本自行校准。

## 三、接口详情

### 3.1 实时行情 realhead

**用途**：自选股列表/行情卡片的核心接口，一次返回一只股票（也支持指数、ETF、板块）的现价、涨跌、成交、买卖一档、资金流、市值、估值等。板块用法见 3.12。

**请求**

```
GET https://d.10jqka.com.cn/v2/realhead/{symbol}/last.js
```

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| symbol | path | 是 | 见 2.3.2，如 `hs_600000`、`hs_000001`、`hs_1A0001`、`hs_1B0300`、`48_881273` |
| callback | query | 否 | 实测无作用，回调名固定为 `quotebridge_v2_realhead_{symbol}_last` |

**请求示例**

```bash
curl "https://d.10jqka.com.cn/v2/realhead/hs_600000/last.js" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://stockpage.10jqka.com.cn/"
```

**响应结构（2026-10-31 实测）**

```js
quotebridge_v2_realhead_hs_600000_last({
  "items": {
    "5": "600000",
    "10": "10.02",
    "...": "...",
    "name": "浦发银行",
    "marketid": "17",
    "marketType": "HS_stock_sh",
    "stockStatus": "闭市",
    "stop": 0,
    "time": "2026-10-31 01:10:25 北京时间",
    "updateTime": "2026-10-30 15:30",
    "profit": "是",
    "vote_diff": "否",
    "equalRights": "是",
    "registration": "否"
  }
})
```

> 顶层只有 `items` 一个 key，证券名称、市场、状态、时间等元信息**都在 `items` 内**。解析用 `it = d["items"]`；兼容写法：`it = d.get("items", d)`、`name = it.get("name") or d.get("name")`。

**items 内的元信息字段**

| key | 类型 | 说明 |
|---|---|---|
| name | string | 证券名称 |
| marketid | string | 市场号：17 沪A / 33 深A / 151 北交所 / 18 沪B / 20 沪ETF / 36 深ETF / 16 沪指数 / 32 深指数 / 48 板块 |
| marketType | string | 如 `HS_stock_sh`、`HS_stock_sz`、`HS_stock_gem`、`HS_stock_kcb`；指数/板块可能为空 |
| stockStatus | string | 交易状态文本：`交易` / `闭市` / `--`（指数、板块） |
| stop | int | 停牌标记，`0` 为正常 |
| time | string | 服务器当前时间 |
| updateTime | string | 行情快照时间（收盘后为 15:30 或 15:00） |
| profit / vote_diff / equalRights / registration | string | 是否支持分红/投票/同权/登记的标记（`是`/`否`），非数值；指数/板块无这些 key |

import re, json, requests

def get_jsonp(url):
    r = requests.get(url, headers={
        "User-Agent": "Mozilla/5.0 (Linux; Android 13)",
        "Referer": "https://stockpage.10jqka.com.cn/",
    }, timeout=10)
    r.raise_for_status()
    m = re.search(r"\((.*)\)\s*;?\s*$", r.text, re.S)
    return json.loads(m.group(1))

def get_realhead(symbol="hs_600000"):
    d = get_jsonp(f"https://d.10jqka.com.cn/v2/realhead/{symbol}/last.js")
    it = d.get("items", d)                    # 元信息也在 items 内
    return {
        "name": it.get("name") or d.get("name"),
        "code": it.get("5"),
        "price": float(it.get("10") or 0),
        "pre_close": float(it.get("6") or 0),
        "open": float(it.get("7") or 0),
        "high": float(it.get("8") or 0),
        "low": float(it.get("9") or 0),
        "volume": float(it.get("13") or 0),   # 股
        "amount": float(it.get("19") or 0),   # 元
        "buy1": it.get("24"), "buy1_vol": it.get("25"),
        "sell1": it.get("30"), "sell1_vol": it.get("31"),
        "turnover": float(it.get("1968584") or 0),  # %
        "pe_ttm": float(it.get("2942") or 0),
        "pb": float(it.get("592920") or 0),
        "float_mv": float(it.get("3475914") or 0),
        "total_mv": float(it.get("3541450") or 0),
        "status": it.get("stockStatus"),
        "update_time": it.get("updateTime") or d.get("updateTime"),

|---|---|---|---|

- `open` 字段实测为 0，不要当开盘价使用；开盘价取第一条分时价格或 realhead 的 `7`。

**Python 解析**

```python
import re
import requests

HEADERS = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                         "AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36"}
PAT = re.compile(r"所属申万行业[：:]\s*</strong>\s*<span>(.*?)</span>", re.S)

def get_sw_industry(code, timeout=15):
    url = f"https://basic.10jqka.com.cn/{code}/company.html"
    r = requests.get(url, headers=HEADERS, timeout=timeout)
    r.encoding = "gbk"                      # 页面是 GBK，必须显式指定
    m = PAT.search(r.text)
    if not m:                                # 港股/美股/无效代码是“200 + 错误页”，没有该字段
        return None
    raw = re.sub(r"\s+", " ", m.group(1)).strip()
    l1, _, l2 = raw.partition("—")
    return {"code": code, "sw_l1": l1.strip(), "sw_l2": l2.strip(), "raw": raw}

print(get_sw_industry("600519"))
# {'code': '600519', 'sw_l1': '食品饮料', 'sw_l2': '白酒Ⅱ', 'raw': '食品饮料 — 白酒Ⅱ'}
```

**批量与缓存建议**

```python
from concurrent.futures import ThreadPoolExecutor
import time

def batch_sw(codes, workers=3, interval=0.35):
    def one(c):
        time.sleep(interval)                 # 页面 120~200KB，属于重接口，务必限速
        try:
            return get_sw_industry(c)
        except Exception:
            return None
    with ThreadPoolExecutor(max_workers=workers) as ex:
        return list(ex.map(one, codes))
```

- 申万分类一年只调整 1~2 次（通常 6 月/12 月），把 `code -> (sw_l1, sw_l2)` 落本地 JSON/SQLite，**缓存 7 天以上**完全够用，没必要每次刷新行情都拉一遍。
- 页面里同时有 `所属地域`、`公司名称`、`上市日期` 等字段，可用同样的 `<strong class="hltip fl">所属地域：</strong><span>(.*?)</span>` 顺带解析。

**注意事项**

- 只有 `company.html` 有该字段；`field.html`（行业对比）、`operate.html`、手机版 `basic.10jqka.com.cn/mobile/{code}/company.html` 均**不含**“申万”，别抓错页。
- 港股/美股不覆盖：`00700`、`AAPL` 返回 200 但只有 2KB/17KB 的错误页，正则匹配不到——用返回 `None` 作为“不支持”的判据即可。
- 申万二级名称带罗马数字后缀（`Ⅱ`/`Ⅲ`），做分组统计时注意别按字符截断。
- 这页是**同花顺行业体系之外**的申万分类；`3.7` 的 `concept.json` 是概念板块，两者不能互相替代。
- 页面结构属于同花顺前端实现，改版后正则可能失效，建议在解析失败时降级为“缺失”而不是抛异常。
- 北交所旧代码段（如 `832000`）的申万行业仍能从 `company.html` 取到，但这些代码在 realhead 里返回空响应（见 1.2），做行情时需注意区分。

所以标准做法：拉日 K → 取收盘价 → 自己算 MACD(12,26,9)，柱子按国内软件习惯乘 2：

```python
import json
import re
import requests

HEADERS = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                         "AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36"}

def ema(values, n):
    k = 2 / (n + 1)
    out = [values[0]]
    for v in values[1:]:
        out.append(v * k + out[-1] * (1 - k))
    return out

def macd(closes, fast=12, slow=26, signal=9):
    dif = [a - b for a, b in zip(ema(closes, fast), ema(closes, slow))]
    dea = ema(dif, signal)
    bar = [2 * (a - b) for a, b in zip(dif, dea)]   # 国内软件习惯：MACD 柱 = 2*(DIF-DEA)
    return dif, dea, bar

def get_block_kline(block_code, years=(2024, 2025, 2026)):
    rows = {}
    for y in years:
        url = f"https://d.10jqka.com.cn/v6/line/48_{block_code}/01/{y}.js"
        r = requests.get(url, headers=HEADERS, timeout=20)
        m = re.search(r"\((.*)\)\s*;?\s*$", r.text, re.S)
        if not m:
            continue
        for rec in json.loads(m.group(1)).get("data", "").split(";"):
            p = rec.split(",")
            if len(p) > 4:
                rows[p[0]] = (float(p[1]), float(p[2]), float(p[3]), float(p[4]))
    dates = sorted(rows)
    return dates, [rows[d][3] for d in dates]   # 收盘价序列

dates, closes = get_block_kline("881273")
dif, dea, bar = macd(closes)

for d, c, a, b, m in list(zip(dates, closes, dif, dea, bar))[-5:]:
    print(d, f"close={c:.3f} DIF={a:.3f} DEA={b:.3f} MACD={m:.3f}")
```

### 3.13 筹码分布（个股 / 板块）

**先给结论**：同花顺**没有公开的筹码分布数据接口**，个股和板块都没有。App / PC 客户端里的筹码分布是本地用「K 线 + 换手率」算出来的。实测排除：

| 尝试 | 结果 |
|---|---|
| `d.10jqka.com.cn/v6/cyq/*`、`v2/cyq/*`、`v4/cyq/*` | 404 |
| `d.10jqka.com.cn/v6/chip/*`、`v2/chip/*` | 404 |
| `d.10jqka.com.cn/v6/line/hs_600519/cyq.js` | 404 |
| `eq.10jqka.com.cn/open/api/stock_view_v2/{cyq,chip,cost,position}/*.json` | 404 |
| `basic.10jqka.com.cn/600519/position.html` | 是“主力持仓”，不是筹码分布 |
| APK 内 `assets/RS/rs*.rc`、`classes*.dex` 搜 `cyq` / `chip` / `筹码` | 无可用的筹码接口 URL（命中均为 `policyQualifier` 之类误匹配） |

好消息是：用 3.1/3.4 的 K 线接口 + 换手率，**可以完整复算**，算法以同花顺官方《筹码分布的原理》为准。

#### 算法（同花顺官方口径）

> 筹码分布就是把历史上每个价位的成交量叠加起来，判断当前所有流通股的持仓成本；历史成交的一部分会在后面的交易日被抛出，衰减比例就是每天的换手率。

官方例子：1000 万流通盘，前天均价 10 元成交 200 万（20% 换手），昨天均价 11 元成交 300 万（30%），今天均价 12 元成交 400 万（40%），则当前筹码为：

| 成本价 | 剩余筹码 |
|---|---|
| 10 元 | 200 × (1−30%) × (1−40%) = 84 万 |
| 11 元 | 300 × (1−40%) = 180 万 |
| 12 元 | 400 万 |

每天的动作只有两步：

```
旧筹码 *= (1 - 当日换手率)；当日换手的那部分筹码重新分配到今天的价格上
```

**软件里可调参数**（PC 端“筹码峰”设置）：

| 参数 | 取值 | 说明 |
|---|---|---|
| 当日成本算法 | `0` 平均分布 / `1` 三角分布 | 平均：全部记在当日均价；三角：在最低价—均价—最高价之间三角分配 |
| 精度 | 一般 `2` | 价格分箱精度 |
| 起始位置 | `0` 当天 / `1` 前一天 … | 从哪一天开始累加 |
| 换手衰减系数 | 默认 `1` | 实际衰减 = 换手率 × 系数；可放大以加快筹码换手 |

**输出指标**（软件筹码图上那三个数）：

- 平均成本 = Σ(价格 × 筹码) / Σ筹码
- 获利比例 = 现价以下的筹码占比
- 90% 成本区间 = 筹码累计 5% 和 95% 分位对应的价格

#### 个股实现

   日期     开      高       低       收      成交量      成交额     换手率%

```python
import json, re, requests

HEADERS = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                         "AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36"}

def daily(sym, years=(2024, 2025, 2026)):
    rows = {}
    for y in years:
        r = requests.get(f"https://d.10jqka.com.cn/v6/line/{sym}/01/{y}.js", headers=HEADERS, timeout=20)
        m = re.search(r"\((.*)\)\s*;?\s*$", r.text, re.S)
        if not m:
            continue
        for rec in json.loads(m.group(1)).get("data", "").split(";"):
            p = rec.split(",")
            if len(p) < 8:
                continue
            rows[p[0]] = dict(date=p[0], h=float(p[2]), l=float(p[3]), c=float(p[4]),
                              vol=float(p[5]), amt=float(p[6]),
                              trn=float(p[7]) / 100 if p[7] else 0.0)
    return [rows[k] for k in sorted(rows)]

def chip_dist(rows, tri=True, nbins=600):
    lo = min(r["l"] for r in rows)
    hi = max(r["h"] for r in rows)
    step = (hi - lo) / nbins
    grid = [lo + step * (i + 0.5) for i in range(nbins)]
    dist = [0.0] * nbins
    dist[min(nbins - 1, int((rows[0]["amt"] / rows[0]["vol"] - lo) / step))] = 1.0
    for r in rows:
        t = min(1.0, max(0.0, r["trn"]))
        dist = [x * (1 - t) for x in dist]           # 换手衰减
        avg = r["amt"] / r["vol"] if r["vol"] else r["c"]
        if not tri or r["h"] <= r["l"]:
            dist[min(nbins - 1, int((avg - lo) / step))] += t
        else:
            w = [(g - r["l"]) / (avg - r["l"]) if g <= avg else (r["h"] - g) / (r["h"] - avg) for g in grid]
            w = [max(0.0, x) for x in w]
            s = sum(w) or 1.0
            dist = [d + t * x / s for d, x in zip(dist, w)]
    return grid, dist

def chip_metrics(rows, tri=True):
    grid, dist = chip_dist(rows, tri)
    total = sum(dist)
    close = rows[-1]["c"]
    avg_cost = sum(g * d for g, d in zip(grid, dist)) / total
    profit = sum(d for g, d in zip(grid, dist) if g < close) / total
    acc, p5, p95 = 0.0, None, None
    for g, d in zip(grid, dist):
        acc += d
        if p5 is None and acc >= total * 0.05: p5 = g
        if p95 is None and acc >= total * 0.95: p95 = g
    peak = grid[max(range(len(dist)), key=lambda i: dist[i])]
    return dict(avg_cost=avg_cost, profit=profit, p5=p5, p95=p95, peak=peak, close=close)

print(chip_metrics(daily("hs_600519")))
```

## 五、自选股批量行情示例

同花顺没有公开的“批量 realhead”接口，自选股需要**逐只并发请求**。建议并发数 ≤ 4~5，并做 30~60 秒缓存。

```python
import re
import json
import time
import requests
from concurrent.futures import ThreadPoolExecutor, as_completed

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Linux; Android 13; Pixel 7) AppleWebKit/537.36 "
                  "(KHTML, like Gecko) Chrome/120.0 Mobile Safari/537.36",
    "Referer": "https://stockpage.10jqka.com.cn/",
}

def get_jsonp(url, timeout=10):
    r = requests.get(url, headers=HEADERS, timeout=timeout)
    r.raise_for_status()
    m = re.search(r"\((.*)\)\s*;?\s*$", r.text, re.S)
    if not m:
        raise ValueError(f"不是合法 JSONP: {url}")
    return json.loads(m.group(1))

def fetch_one(symbol):
    """symbol 形如 hs_600000"""
    d = get_jsonp(f"https://d.10jqka.com.cn/v2/realhead/{symbol}/last.js")
    it = d.get("items", {})
    def f(k, default=0.0):
        v = it.get(k)
        try:
            return float(v)
        except (TypeError, ValueError):
            return default
    return {
        "symbol": symbol,
        "name": it.get("name") or d.get("name"),
        "price": f("10"),
        "pct": f("199112"),
        "chg": f("264648"),
        "open": f("7"),
        "high": f("8"),
        "low": f("9"),
        "pre_close": f("6"),
        "volume": f("13"),       # 股
        "amount": f("19"),       # 元
        "turnover": f("1968584"),# %
        "buy1": it.get("24"),
        "sell1": it.get("30"),
        "status": it.get("stockStatus"),
        "update_time": it.get("updateTime") or d.get("updateTime"),
    }

def fetch_watchlist(symbols, workers=4, interval=0.2):
    result = []
    with ThreadPoolExecutor(max_workers=workers) as pool:
        futures = {pool.submit(fetch_one, s): s for s in symbols}
        for fut in as_completed(futures):
            s = futures[fut]
            try:
                result.append(fut.result())
            except Exception as e:
                result.append({"symbol": s, "error": str(e)})
            time.sleep(interval)  # 简单限速
    return result

if __name__ == "__main__":
    watchlist = [
        "hs_600000",  # 浦发银行
        "hs_000001",  # 平安银行
        "hs_300750",  # 宁德时代
        "hs_510300",  # 沪深300ETF
        "hs_1A0001",  # 上证指数
    ]
    for row in fetch_watchlist(watchlist):
        print(row)
```

def fetch_daily(symbol, year=None):
    path = f"{year}.js" if year else "last.js"
    d = get_jsonp(f"https://d.10jqka.com.cn/v6/line/{symbol}/01/{path}")
    rows = []
    for rec in d.get("data", "").split(";"):
        if not rec:
            continue
        p = rec.split(",")
        rows.append({
            "date": p[0], "open": float(p[1]), "high": float(p[2]),
            "low": float(p[3]), "close": float(p[4]),
            "volume": float(p[5]), "amount": float(p[6]),
            "turnover": float(p[7] or 0),
        })
    return rows

## 六、字段与使用坑速查

| 项目 | 说明 |
|---|---|
| JSONP 三套结构 | realhead 顶层是 `{"items":{...}}`；time 顶层是 `{"hs_xxx":{...}}`；line 字段在顶层。不要用同一套取值代码 |
| realhead 元信息 | `name/marketid/stockStatus/time/updateTime/stop` 都在 `items` 内，不在外层（2026-10-31 实测） |
| 数字类型 | 并非全部字符串：`stop` 是数字，其余多为字符串；空串和 `-1` 很常见，统一宽松转换 |
| 市场判断 | 用 `items["marketid"]`（17 沪A / 33 深A / 151 北交所 / 20/36 ETF / 16/32 指数 / 48 板块）；`items["12"]` 口径不稳，勿用 |
| 37/38/39 | 个股/ETF 恒为 `-1`；指数/板块为“成分股数/上涨家数/下跌家数” |
| 市值字段 | 个股/ETF 用 `3475914` 流通市值、`3541450` 总市值；指数/板块用 `90` 流通、`92` 总市值；个股/ETF 的 `90/92` 是空串 |
| items 键数 | 74~84 个，随品种变化；文档只列可解释字段，未列出的忽略 |
| 价格小数位 | 股票 2 位，ETF/基金 3 位；不要写死 2 位 |
| 成交量单位 | realhead `13`、time 第 5 列、line 第 6 列都是“股”口径；ETF/LOF 实为“份”，数值含义相同 |
| 成交额单位 | realhead `19`、time 第 3 列、line 第 7 列均为**元** |
| 时间字段 | `time`/`updateTime` 是北京时间字符串（不带时区标记），个股 15:30、指数/板块 15:00 收盘快照 |
| 分时累计/单分钟 | time 的成交额/成交量都是**单分钟值**；均价是累计 VWAP。全天求和与 realhead `13` 会差 1%~2%（竞价/盘后口径） |
| 15:30 盘后 | 部分股票分时含 15:05-15:30 盘后交易（最多约 268 条），做分时图时按需截断 |
| K 线复权 | 01/11/21/41/51/61/71 为前复权；02/42/52/72 为后复权；不要混用 |
| last.js 条数 | 固定最近 140 根；全历史用“按年文件”，不要用 all.js 硬解 |
| 板块成分股 | 详情页最多 100 只（5 页）；用 realhead `37` 校验是否截断 |
| 批量 | realhead 不支持逗号批量，逐只请求并限速 |
| 北交所 | 920 段可用（`hs_920002`）；430/830/870 段返回 200 + 0 字节 |
| 港股/美股 | `hk_/us_` 返回 404 + 空响应，需另找数据源 |
| 指数代码 | `hs_000905` 会命中股票；中证/沪深系列用 `1B`（`1B0300`/`1B0905`/`1B0688`）或 `399` 前缀 |
| 盘后数据 | 收盘后 `updateTime` 变为 15:30（个股）/15:00（指数、板块）；以它判断数据是否已更新 |
| 交易日历 | 没有独立接口；用分时响应的 `date` 或日 K 最新日期判断“今天是否交易日/是否已收盘” |
| 编码 | F10/板块 HTML 为 GBK；news JSON 为 UTF-8；d.10jqka 中文为 `\uXXXX` |
| CORS | d.10jqka、eq 的 open/api 有 `ACAO: *`；**news 没有**，前端需代理 |
| 反爬 | `qd.10jqka.com.cn/quote.php`、`q.10jqka.../ajax/1/` 有 JS 挑战（401）；news 无 UA 返回 403 |
| 缓存 | 多数接口 `max-age=60`，客户端缓存 30~60 秒可显著降低请求量 |
| 稳定性 | 未公开文档的 Web 接口，字段和路径可能随时调整；生产使用需做降级容错与告警 |
