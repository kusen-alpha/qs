# 盘盯盯 0.4.6 A 股数据接口（实测可用版）

本文只保留与 A 股相关的接口，并且只纳入 2026-10-27 实际请求成功、能返回有效数据的接口。所有响应示例均来自当次真实请求（贵州茅台 `600519`、平安银行 `000001`、上证指数 `000001`）。

## 0. 测试结论

| # | 接口 | 方法 | 实测状态 | 耗时 | 结论 |
|---|---|---|---|---|---|
| 1 | `push2.eastmoney.com/api/qt/ulist.np/get` | GET | 200 | 0.23–0.28s | 可用，返回多只 A 股实时行情 |
| 2 | `push2his.eastmoney.com/api/qt/stock/kline/get` | GET | 200 | 0.22s | 可用，日/周/月/分钟共用此接口 |
| 3 | `push2his.eastmoney.com/api/qt/stock/trends2/get` | GET | 200 | — | 可用，返回当日分时 |
| 4 | `searchadapter.eastmoney.com/api/suggest/get` | GET | 200 | — | 可用，返回 A 股代码/名称/secid |
| 5 | `hq.sinajs.cn`（A 股指数） | GET | 200 | — | 可用，项目仅用于测速 |
| 6 | `qt.gtimg.cn`（A 股指数） | GET | 200 | — | 可用，项目仅用于测速 |
| — | Zealink 系列（A 股 K 线备用源） | GET/POST | TLS 握手失败 | — | 当前不可用，已剔除 |

测试环境：Windows PowerShell + `curl.exe` / Node 18 `fetch`，直连公网，无代理。请求均带 `Referer` 与桌面 UA。

> **限流提示（实测）**：东方财富对连续请求敏感。同一次测试中连续发起约 10 次请求后，`push2` 与 `push2his` 会主动断开连接（curl 报 `schannel: server closed abruptly`，Node 报 `UND_ERR_SOCKET`），间隔 75 秒仍未恢复。应用按 4 秒轮询单次请求不受影响，批量抓取需自行节流（建议 ≥1 秒/次）并在失败后退避重试。

### 0.1 网络访问方式

- 项目内通过 [`src/utils/http.js`](dp/src/utils/http.js) 的 `request()` 发起：
  - Tauri 环境：`@tauri-apps/api/http` 的 `fetch`，`responseType: 2`（JSON）；
  - 浏览器环境：原生 `fetch`，响应文本再 `JSON.parse`。
- Tauri 放行域名（[tauri.conf.json](dp/src-tauri/tauri.conf.json#L34-L47)）中与 A 股相关的部分：

```
https://push2.eastmoney.com/*        （由 https://*.eastmoney.com/* 覆盖）
https://push2his.eastmoney.com/*
https://searchadapter.eastmoney.com/*
https://hq.sinajs.cn/*
https://qt.gtimg.cn/*
```

### 0.2 secid 规则

东方财富使用 `市场码.代码`：

| 市场码 | 市场 | 示例 |
|---|---|---|
| `0` | 深市（含创业板） | `0.000001` 平安银行 |
| `1` | 沪市（含科创板） | `1.600519` 贵州茅台 |
| `2` | 北交所 | `2.430047` |

A 股范围过滤串（实时接口使用）：

```
m:0 t:6, m:0 t:80, m:1 t:2, m:1 t:23, m:0 t:81 s:2048
```

### 0.3 统一请求头

实时行情与 K 线：

| Header | 值 |
|---|---|
| `Host` | `push2.eastmoney.com` / `push2his.eastmoney.com` |
| `Referer` | `http://quote.eastmoney.com/`（K 线用 `https://quote.eastmoney.com/` 也可） |
| `Connection` | `keep-alive` |
| `Accept` | `*/*` |
| `User-Agent` | `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/108.0.0.0 Safari/537.36 Edg/108.0.1462.54` |

搜索接口：`Referer: https://www.eastmoney.com/`，`Host: searchadapter.eastmoney.com`，其余相同。

## 1. 实时行情（自选列表轮询）

- 代码：[`src/api/eastmoney.js`](dp/src/api/eastmoney.js#L30-L84)
- 调用方：[`Table.vue`](dp/src/components/monitor/Table.vue#L244-L261)
- 触发：主窗口挂载后循环；成功 4 秒一次，失败退避为 20 秒
- 用途：自选表报价、持仓盈亏、价格/涨跌幅提醒、详情页头部行情

### 1.1 请求

```
GET https://push2.eastmoney.com/api/qt/ulist.np/get
```

| 参数 | 值 | 说明 |
|---|---|---|

| `pz` | `500` | 每页条数 |
| `po` | `1` | 降序 |
| `np` | `1` | 返回精简结构 |
| `ut` | `bd1d9ddb04089700cf9c27f6f7426281` | 固定 token |
| `fltt` | `2` | 小数按浮点返回 |
| `invt` | `2` | 与 `fltt` 配套 |
| `fid` | `f3` | 按涨跌幅排序 |
| `fs` | `m:0 t:6,m:0 t:80,m:1 t:2,m:1 t:23,m:0 t:81 s:2048` | A 股市场过滤 |
| `fields` | `f1,f2,f3,f4,f5,f6,f7,f8,f9,f10,f12,f13,f14,f15,f16,f17,f18,f20,f21,f23,f24,f25,f22,f11,f62,f115,f152` | 字段白名单 |

### 1.3 字段映射

### 1.4 解析行为

- 只有 `res.ok && res.data.data` 存在时读取 `data.diff`，否则返回空数组。
- 按 `secid` 匹配自选；未返回的标的用 `'-'` 占位。
- 持仓盈亏在本地计算，不再请求接口（公式见附录 B）。
- 失败不弹窗，只调整轮询间隔。

## 2. K 线（日/周/月/分钟）

- 代码：[`src/utils/kline.js`](dp/src/utils/kline.js#L74-L158)
- 调用方：[`HQKLineChart.vue`](dp/src/components/detail/HQKLineChart.vue#L477-L493)
- 用途：详情页主图与副图指标计算

### 2.1 请求

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
```

| 参数 | 值 | 说明 |
|---|---|---|
| `fields1` | `f1,f2,f3,f4,f5,f6,f7,f8,f9,f10,f11,f12,f13` | 标的信息 |
| `fields2` | `f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61` | K 线行字段 |
| `beg` | 日/周/月 `20150101`；分钟 `0` | 起始日期 |
| `end` | `20500101` | 结束日期 |
| `rtntype` | `6` | 返回格式 |
| `secid` | `1.600519` | 标的 |
| `klt` | 日 `101`、周 `102`、月 `103`、5/15/30/60 分钟 | 周期 |
| `fqt` | `0` 不复权、`1` 前复权、`2` 后复权 | 复权 |
| `ut` | `7eea3edcaed734bea9cbfc24409ed989` | 固定 token |

周期枚举见 [`KLINE_PERIOD_OPTIONS`](dp/src/utils/kline.js#L11-L19)，复权枚举见 [`KLINE_RIGHT_OPTIONS`](dp/src/utils/kline.js#L21-L25)。HQChart 的年线周期 `period=3` 会被降级成月线。

测试命令（日线）：

```bash
curl -s "https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.600519&klt=101&fqt=1&beg=20261001&end=20500101&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61&ut=7eea3edcaed734bea9cbfc24409ed989" \
  -H "Referer: https://quote.eastmoney.com/"
```

分钟线只改 `klt=5|15|30|60` 且 `beg=0`，其余参数相同。

```json
{

  "lt": 1,
  "full": 0,

    "code": "600519",
    "market": 1,
    "name": "贵州茅台",
    "klines": [
      "2026-10-08,1252.90,1255.79,1258.00,1242.00,25168,3145413157.00,1.27,-0.22,-2.83,0.20",
      "2026-10-09,1255.42,1263.00,1282.00,1255.42,35111,4453223189.00,2.12,0.57,7.21,0.28",

    ]
  }

```

`klines` 每行索引：

| 索引 | 含义 | 代码处理 |
|---|---|---|
| 0 | 日期（分钟线为 `YYYY-MM-DD HH:mm`） | `date` |
| 1 | 开盘 | `open` |
| 2 | 收盘 | `close` |
| 3 | 最高 | `high` |
| 4 | 最低 | `low` |
| 5 | 成交量（手） | `volume = 值 × 100`（换算成股） |
| 6 | 成交额（元） | `amount` |
| 7 | 振幅（%） | 忽略 |
| 8 | 涨跌幅（%） | `changePct` |
| 9 | 涨跌额 | 忽略 |
| 10 | 换手率（%） | 忽略 |

解析规则：字段少于 7 个、或 OHLC 任一非有限数的行直接丢弃。昨收取顶层 `data.preKPrice`（本次响应未返回该字段时，`preClose` 为 `null`，不影响蜡烛绘制）。

### 2.3 回退说明

代码还有 Zealink 备用源（`KLine2` 日/周/月、`KLine3` 分钟）。实测 `opensource.zealink.com` 与 `opensourcecache.zealink.com` 均无法完成 TLS 握手（curl 35、Node `fetch failed`，DNS 解析到 `28.0.0.229`），当前不可用，故不作为本文件的可用接口。东方财富失败时，当前实际会落到本地演示数据 `fallbackKline`。

## 5. A 股备用行情源（已实测，项目仅用于测速）

## 附录 B：本地计算

| 指标 | 公式 |
|---|---|
| 持仓市值 | `price × position_num` |
| 持仓盈亏 | `(price − buy_price) × position_num` |
| 持仓收益率 | `持仓盈亏 ÷ (buy_price × position_num)` |
| 今日盈亏 | `Σ price_diff × amount` |
| 今日收益率 | `今日盈亏 ÷ Σ (price − price_diff) × amount` |
| 总盈亏 | `Σ (price − buy_price) × amount` |
| 总收益率 | `总盈亏 ÷ Σ buy_price × amount` |
